# 3D Building Generator

Приложение разработано для автоматической генерации трёхмерных моделей зданий и помещений на основе обычных фотографий. Система позволяет без специализированного оборудования получить готовую 3D-модель реального объекта, пригодную для просмотра, редактирования и публикации в вебе.

## Возможности

- Автоматическое извлечение ключевых точек из набора фотографий
- Сопоставление изображений и определение пространственных взаимосвязей между ними
- Разреженная 3D-реконструкция сцены методом Structure-from-Motion (SfM)
- Плотная реконструкция с построением карт глубины (PatchMatch Stereo)
- Слияние карт глубины в единое плотное облако точек
- Построение полигональной сетки методом Poisson Surface Reconstruction
- Конвертация готовой модели в формат GLB для использования в браузере и сторонних приложениях
- Графический интерфейс с предпросмотром фотографий, логом событий и прогресс-баром

## Технологии

- **Python 3** — основной язык разработки
- **COLMAP** — ядро фотограмметрической реконструкции
- **PySide6 (Qt6)** — графический интерфейс
- **trimesh** — конвертация 3D-моделей

## Поддерживаемые форматы

Входные изображения: `JPG`, `JPEG`, `PNG`, `BMP`

Выходные модели: `PLY` (облако точек, полигональная сетка), `GLB` (готовая модель)
